# 확인 필요 목록

## 모드팩 데이터팩으로 출현 데이터 교체 (모드팩 1.7.42)
공식 위키가 모드팩보다 오래된 내용이라(예: 카르본이 네더에서 블레이즈 막대기를 떨어뜨림, 쌍검킬이 네더에서도 나옴), 1~9세대 출현 데이터를 모드팩 안의 실제 데이터로 다시 만들었어요. 아래 세대별 기록 중 "위키 카드" 이야기는 예전 위키 기준 기록이에요.
- 출처: Modrinth COBBLEVERSE 1.7.42 `.mrpack` → `overrides/datapacks/COBBLEVERSE-DP-v31.zip`(우선) + 그 데이터팩이 덮어쓰지 않은 코블몬 1.7.3·cobblemon-additions 4.1.6 출현 파일. Mega Showdown·zamega의 출현 파일은 모두 데이터팩이 같은 경로로 덮어써요. 프리셋(spawn_detail_presets)은 항목 조건에 합쳐서 옮겼어요.
- 결과: 출현 항목 2,052개 → 2,230개. 종 1,018 → 1,017종(폴리곤2가 빠짐, 아래 참고). 출현 데이터가 없는 종: 233 폴리곤2, 773 실버디, 809 멜메탈, 880~883 화석 포켓몬, 1000 타부자고.
- 뺀 것
  - 낚시 출현(빈티나·밀로틱은 낚시로만 나와서 `낚시` 조건으로 넣었어요).
  - 설치되지 않은 모드(aether, biomesoplenty, byg, betternether, wythers 등)의 바이옴에만 나오는 항목 34개. 예: 식스테일·나인테일·불꽃숭이 계열의 `nether/is_forest`, 눈꼬마·바닐프티 계열의 `nether/is_frozen`, 페라페·꼬시레·짜랑꼬 계열의 `is_tropical_island`, 베베솔트·초롱순 계열의 `nether/is_quartz`. 실제 게임에서 나올 수 없어요.
  - 데이터팩 자체 오류로 나올 수 없는 항목: 가라르 코산호 `is_warm_ocean`(태그 표시 # 빠짐), 폴리곤2 `#cobblemon:end`, 듀오시온 `#cobblemon:lush`(없는 태그), 피카츄 `cobbleverse:not_spawn`(일부러 안 나오게 한 항목). 그래서 폴리곤2는 출현 데이터가 없어요.
- 바이옴 태그는 Terralith 데이터팩이 태그에 더한 값을 빼고 풀었어요(예전 위키와 같은 방식). 그래도 코블몬 태그 자체에 Terralith 바이옴이 들어 있어서 알파 섬·하늘 섬 등 위키에 없던 Terralith 바이옴이 새로 보여요.
- 모드팩의 biome_replacer 설정(일부 Terralith 바이옴을 다른 바이옴으로 바꿈)은 반영하지 않았어요. 실제 월드에는 없는 바이옴 이름이 보일 수 있어요.
- 데이터팩에 장소가 비어 있는 전설 12종(유크시·엠라이트·아그놈·디아루가·펄기아·히드런·레지기가스·기라티나·크레세리아·피오네·마나피·버드렉스, 장소가 `cobbleverse:custom_spawn`뿐이고 출현 가중치 0)은 레벨·희귀도만 데이터팩 값을 쓰고, 장소는 예전 위키 값을 남겼어요(피오네는 교배로만).
- 출현 풀 밖에서 얻는 방법은 예전 위키 카드를 그대로 덧붙였어요: 뮤츠·타입:널의 되살리기 머신(Resurrection Machine), 레쿠쟈 색이 다른 개체(엔드 출구 차원문). 뮤츠는 데이터팩상 로켓단 라디오타워(성도) 특수 출현도 있어요.
- 화면에 똑같이 보이는 항목(조건·장소·레벨·희귀도가 모두 같음, 예: 바닐라 마을과 추가 모드 마을)은 한 줄로 합쳤어요. 출현 확률(가중치)은 화면에 없어서 합쳐도 보이는 정보는 같아요.

## 공통
- 포켓몬 한국어 이름과 종족값은 npm 패키지 `pokemon`(공식 다국어 이름)과 `@pkmn/dex`(원작 최신 세대 종족값)로 확인했어요. 이 두 자료는 기존 1~2세대 251종의 이름·종족값과 모두 일치했어요.
- 모드 바이옴(Terralith 등)과 모드 구조물은 공식 한국어 이름이 없어서 뜻을 살려 옮겼어요. 아래 세대별 목록에 적었어요.
- 메가진화는 원작 6세대(X·Y, 오메가루비·알파사파이어) 것만 넣었어요. Legends Z-A에서 새로 나온 메가진화와 원시회귀(가이오가·그란돈)는 넣지 않았어요.
- `app.js`의 지방 전용 구조물 표시는 관동·성도·호연·신오·네더·엔드만 알아봐요. 하나·칼로스·알로라·가라르·팔데아 구조물은 이름에 괄호 지방이 있어도 "OO 전용 구조물" 표시가 붙지 않아요(화면 코드는 고치지 않았어요).

## 특성·드롭 아이템
- 출처: 코블버스 1.7.42 모드팩(Modrinth)에 들어 있는 코블몬 1.7.3의 종족 데이터(GitLab 1.7.3 태그)와, 같은 모드팩의 Mega Showdown 1.8.4가 덮어쓴 종족 28개·드롭 추가 3개(클레피, 멜탄, 멜메탈). 이름과 설명은 코블몬·마인크래프트·Mega Showdown 게임 한국어 번역이에요.
- 확률이 적혀 있지 않은 드롭은 코블몬 규칙상 100%(개수 범위만큼)라서 100%로 표시했어요. 같은 아이템이 두 번 적힌 경우(예: 잠만보의 사과)도 데이터 그대로 두 줄로 보여요.
- 폼: 알로라·가라르·히스이·팔데아 등 코블몬 데이터에 따로 있는 폼은 그 폼의 특성·드롭을 썼어요(63개). 데이터에 없는 폼은 기본형 값을 보여 줘요.
- 코블몬 데이터 오류: 테오키스·앤테이·칠색조의 드롭에 게임에 없는 아이템 ID(`cobblemon:sacred_ash` 성스러운분말, `minecraft:eye_of_ender`)가 있어요. 실제 게임에서는 떨어지지 않을 수 있어서 "(게임에 없는 아이템 ID)"로 표시했어요.
- "고오스: 가스트의 눈물 5%"는 종족 데이터가 아니라 데이터팩의 네더 출현 항목 전용 드롭이에요. 데이터팩 교체 때 위치별 드롭으로 넣었어요(위 "모드팩 데이터팩으로 출현 데이터 교체" 참고). 다른 곳의 고오스는 저주의부적 2.5%, 야파열매 2.5%예요.
