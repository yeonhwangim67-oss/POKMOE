# 확인 필요 목록

Claude Code가 작업하면서 확실하지 않은 번역, 종족값, 위키 표기 이상을 여기에 적어요.

## 공통
- 포켓몬 한국어 이름과 종족값은 npm 패키지 `pokemon`(공식 다국어 이름)과 `@pkmn/dex`(원작 최신 세대 종족값)로 확인했어요. 이 두 자료는 기존 1~2세대 251종의 이름·종족값과 모두 일치했어요.
- 모드 바이옴(Terralith 등)과 모드 구조물은 공식 한국어 이름이 없어서 뜻을 살려 옮겼어요. 아래 세대별 목록에 적었어요.
- 메가진화는 원작 6세대(X·Y, 오메가루비·알파사파이어) 것만 넣었어요. Legends Z-A에서 새로 나온 메가진화와 원시회귀(가이오가·그란돈)는 넣지 않았어요.
- `app.js`의 지방 전용 구조물 표시는 관동·성도·호연·신오·네더·엔드만 알아봐요. 하나·칼로스·알로라·가라르·팔데아 구조물은 이름에 괄호 지방이 있어도 "OO 전용 구조물" 표시가 붙지 않아요(화면 코드는 고치지 않았어요).

## 기존 데이터(1세대)에서 발견한 것
- 77 포니타, 78 날쌩마: 위키 카드의 바이옴 목록에는 `Sunflower Plains`가 없는데 data_gen1.js에는 들어 있어요(`RAT` 상수 사용). 이번 작업 범위가 아니라 고치지 않았어요.
- 199 야도킹 가라르: 원작 종족값(95 65 80 110 110 30)이 기본 야도킹과 다른데 `FORM_STATS`에 `"199|가라르"`가 없어요. 지금은 기본 야도킹 종족값으로 보여요. 마찬가지로 고치지 않았어요.

## 아이템 도감
- 출처와 버전: 일반 아이템 획득 경로는 코블몬 공식 위키(최신 코블몬 기준, 메인 페이지에 1.8.0 표시)를 옮겼어요. LUMYVERSE FAQ에는 코블버스가 코블몬 1.7.3을 쓴다고 적혀 있어서, 위키 내용이 코블버스 실제 게임과 다를 수 있어요. 코블버스 데이터팩이 바꾼 제작법도 반영되지 않았어요.
- 이름과 효과: 코블몬·Mega Showdown(GitHub main 브랜치)·마인크래프트 1.21.1의 공식 한국어 번역 파일을 썼어요. 게임 번역이라 원작 공식명과 다른 경우가 있어요(예: Sinister Tea → "데운 차").
- 위키 표 오기: 숯(Charcoal Stick) 드롭 표에 파이리·리자드·리자몽이 #0006~0008로, 신비의물방울(Mystic Water) 표에 꼬부기·어니부기·거북왕이 #0009~0011로 적혀 있어요. 이름 기준으로 #0004~0006, #0007~0009로 고쳤어요.
- 뺀 것: "Held item"(지닌 물건 설명 문서), "Paintings"(장식용 그림) 문서는 획득 경로가 없어서 넣지 않았어요. 나무열매 효과 목록과 그림 목록 표, 그림으로만 된 표(뿌리가 붙는 블록, 어부 거래 표), 발전 과제 이름 문장, 명령어 예시도 옮기지 않았어요.
- 화석 표에서 위키는 "반드시 들어 있는 구조물"을 굵은 글씨로 표시했는데, 이 페이지에서는 굵은 글씨를 옮기지 못했어요.
- 선사 시대 화석 구조물(Prehistoric Lush Den 등)과 유적 구조물(Decaying Crypt Ruins 등) 이름은 공식 한국어 번역이 없어서 뜻을 살려 옮겼어요.
- 투명부적(Clear Amulet): 위키에 획득 방법이 없어서 "적혀 있지 않음"으로 표시했어요. 깃털은 문서 소개문에 적힌 "1.6.1부터 크리에이티브/명령어로만 얻을 수 있음"을 옮겼어요.
- 코블버스 전용 아이템 75개 중 47개는 번역 파일에 없어서 뜻을 살려 이름을 옮겼어요(에테르 보석, 하늘의 핵, 바다의 핵, 대지의 핵, 루비/사파이어 물방울, 거신 유물, 드림캐처 등). Mega Showdown 아이템과 원작에 있는 아이템(금강옥, 무지개깃털, 은빛깃털, 빨간사슬, 초승달날개, 천계의피리, 악의/물의 족자 등)은 공식 이름을 썼어요.
- LUMYVERSE 표는 이탈리아어판 인물 이름을 써요. 확실한 것은 한국어 공식 이름으로 바꿨어요(Rocco→성호, Camilla→난천, Ivan→아강, Max→마적, Atena→아테나, Giovanni→비주기, Cyrus→태홍). 확신이 없는 인물: Damon → "데이먼", Perula → "페룰라", Lyris → "라이리스", Buck → "현수", Charon → "플루톤", Old Sage → "노승".
- LUMYVERSE 표에서는 유크시를 "입지호수", 아그놈을 "예지호수"로 적고 있어 위키(유크시=예지호수, 아그놈=입지호수)와 반대예요. 표기 그대로 옮기고 "(LUMYVERSE 표기)"를 붙였어요.
- 관장 소환 아이템 36개: 이름은 뜻을 살려 옮겼고, 관장 이름은 이탈리아어판 이름을 한국어 공식 이름으로 바꿨어요(Adriano → 윤진은 확신이 덜해요). LUMYVERSE에 얻는 방법이 적혀 있지 않아요.
- 빠졌던 아이템 추가: 위키에서 분류가 달려 있지 않아 처음에 빠졌던 문서 22개를 추가했어요(민트, 민트 잎, 민트 씨앗, 규토리나무 잎·싹·목재 세트, 사카린나무 잎·묘목·목재 세트, 진화의돌 광석, TM 머신, 회복 장치, PC, 목장 블록, 보물상자, 심층암 수정 코어, 데이터 모니터, 디스크 선반, 서식지 블록, 명판, 다다미·옥돌 블록 세트). 위키에 획득 방법이 없는 Berry Tree, Display Case, Resurrection Machine 문서와 사용자 연습 문서(Faintfulness/…)는 넣지 않았어요.
- 민트: 실제 성격은 바뀌지 않고 능력치 보정만 그 성격처럼 바뀌어요(게임 설명과 위키 모두 같음). 성격 민트 21종의 제작법은 "민트 잎" 항목에 있어요.
- 사용법: 위키 "Usage" 절(102개 문서)을 옮겼어요. 사용법 절의 제작 틀은 격자로 그리지 않고 "이걸로 만들 수 있는 것" 목록으로 줄였어요. 디스크 선반의 음표 칸 배치 표는 그림으로만 되어 있어 옮기지 않았어요.
- 진화의돌 사용법 표: 위키는 돌별로 칸을 나란히 배치한 표라, 돌 이름별 "진화하는 포켓몬" 목록으로 다시 묶었어요. (H.)/(A.)/(G.)는 히스이/알로라/가라르 모습이에요.
- 진화의돌 광석의 바이옴 태그(Desert, Thermal 등)는 태그 이름을 뜻대로 옮겼어요(사막, 온열 등). 실제 태그 이름은 영어예요.
- 사용법 문장에 나오는 블록·아이템 이름은 게임 번역과 대조해서 맞췄어요(예: 규토리나무 잎, 고장난 데이터 모니터, 회복 장치, 포켓몬 미끼). 데인차·포트데스·차데스·그우린차 폼 이름은 앞의 확인 필요 항목과 같아요.
